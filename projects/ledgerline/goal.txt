A pure-Python double-entry bookkeeping library called ledgerline, standard library only, no network access anywhere. Exact API, one implementation module per task: src/ledger/money.py exposes parse_amount(text) -> int returning integer minor units and format_amount(minor_units) -> str, raising ValueError on malformed input. src/ledger/accounts.py exposes an AccountType enum of ASSET, LIABILITY, EQUITY, REVENUE, EXPENSE, an Account dataclass with id, name and type, and normal_balance(account_type) -> str. src/ledger/journal.py exposes a Side enum of DEBIT and CREDIT, a Posting dataclass with account_id, amount_minor and side, and a JournalEntry dataclass with date, memo and postings whose __post_init__ raises ValueError when debits do not equal credits or when there are fewer than two postings. src/ledger/ledger.py exposes a Ledger class with add_entry(entry), balance_of(account_id) -> int, balances() -> dict, and is_balanced() -> bool. src/ledger/trial_balance.py exposes trial_balance(ledger) -> list of TrialBalanceRow dataclasses each with account_id, debit_total and credit_total. src/ledger/reports.py exposes income_statement(ledger, start, end) -> dict and balance_sheet(ledger, as_of) -> dict. src/ledger/csv_import.py exposes parse_csv(text) -> list of JournalEntry parsing date, memo, account, side and amount columns. src/ledger/cli.py exposes main(argv) -> int that reads a CSV file path and prints a trial balance. src/ledger/__init__.py re-exports the public names. Every behaviour is covered by pytest tests written before the implementation exists.
