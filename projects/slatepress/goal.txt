A dependency-free static site generator called slatepress, Python standard library only, no network access anywhere. It converts a directory of Markdown files into a static HTML site, with YAML-ish front matter per page. Exact API, one implementation module per task: src/slatepress/frontmatter.py exposes split_front_matter(text: str) -> tuple of Optional[str] and str, raising ValueError when the opening delimiter is present but never closed, and parse_front_matter(text: str) -> dict of str to str supporting simple key value lines and ignoring comment lines beginning with #. src/slatepress/markdown.py exposes inline_markup(text: str) -> str applying bold with double asterisk, italic with single asterisk and inline code with backticks, and must escape the HTML special characters ampersand, less-than and greater-than FIRST so that markup characters in source text are not treated as markup after escaping. src/slatepress/markdown.py also exposes blocks(text: str) -> str converting ATX headings with between one and six hash characters into h1 to h6 tags, fenced code blocks delimited by three backticks into a pre and code element with the language as a class, and unordered list items beginning with hyphen or asterisk into li elements inside a ul element. src/slatepress/html.py exposes escape(text: str) -> str and page(title: str, body: str, css_link: Optional[str]) -> str producing a complete HTML5 document with the title inserted inside the title element and the body inside the main element. src/slatepress/site.py exposes build_site(source_dir: Path, output_dir: Path) -> list of str returning the output paths written, recursing into subdirectories, skipping any file whose name begins with an underscore or a dot, and copying any non-Markdown file unchanged. src/slatepress/cli.py exposes main(argv: list of str) -> int taking a source directory and an optional output directory defaulting to a directory named _site, returning 0 on success and 2 when the source directory does not exist. src/slatepress/__init__.py re-exports the public names. Every behaviour is covered by pytest tests written before the implementation exists.
